TikTok Publisher

A personal desktop tool for uploading my own videos to TikTok as drafts.

What it does

TikTok Publisher is a command-line tool that runs on its owner's computer. It reads videos from the owner's own Google Drive folders and uploads them to the owner's own TikTok account as drafts, using the TikTok Content Posting API (Upload). The owner then opens each draft in the TikTok app to review, edit and publish it.

Who it is for

This tool is used only by its developer, for their own TikTok account. It is not offered to the public and has no other users.

Permissions used

  • user.info.basic: identify the signed-in account.
  • video.upload: send videos to the account's drafts (inbox). Nothing is published automatically.
